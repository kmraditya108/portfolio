# Kumar Aditya Portfolio

A personal portfolio built with React and Vite, shaped around solutions engineering, technical discovery, rapid prototyping, and enterprise product delivery.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```
